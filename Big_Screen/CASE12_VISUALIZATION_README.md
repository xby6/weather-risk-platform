# 大屏三维地图：蓝色立体与地形纹理

参考用户提供的案例 1、案例 2 截图，在现有 Vue 大屏中加入 Three.js 渲染，不引入原示例的 React 技术栈。保留原有图表、业务接口和经典平面地图。

## 使用

```powershell
cd Big_Screen
npm ci
npm run dev
```

打开大屏（默认 `http://127.0.0.1:6688`），在地图右上角选择：

- **立体态势**：低视角透视镜头、双层悬浮底座、岩灰地表、蓝色渐变侧壁、轮廓流光、点位光柱和指挥看板布局。
- **地理监测**：正交俯视/倾斜镜头、薄地表与高程晕渲、地面网格、轻量风险点、无边框监测图表和独立布局。
- **经典平面**：原有 ECharts 二维地图，适用于不支持 WebGL 的浏览器。

风格选择保存在本机浏览器，默认使用蓝色立体。三维模式支持拖动旋转、滚轮缩放和复位视角。点击城市标签或地图区域可切换城市，现有图表通过原有城市参数联动；城市视图提供区县边界，点击“返回全省”恢复。点位按钮、站点统计卡片仍能打开完整的可搜索点位菜单，选择后显示气象数据和风险详情。

## 数据与边界

- 行政区使用项目已有的辽宁省和 14 个城市 GeoJSON，地图面、名称标签及点位共用 Mercator 投影。
- 点位继续通过现有 `/monitor/screen-all-data` 接口的 `map_points` 获取；无点位时不生成随机业务数据。后端不可用时，底图保留，显示错误和重试入口。
- 风险颜色使用接口报告的等级，光柱仅表达点位及数值的视觉强弱，不生成新的业务风险阈值。无等级时使用中性色。坐标缺失、非法或超出范围的记录不渲染为三维点位。
- **2026-10-20 起使用公开 DEM 数据生成地形晕渲，替换原有程序波纹。** 数据来自 [Mapzen Terrain Tiles](https://registry.opendata.aws/terrain-tiles/)，资源中保留完整来源声明。它并非卫星影像，页面高度经过视觉夸张，色彩为高程着色；原始高程已归一化至 8 位用于展示，不用于精密高程量测。
- 本地资源分辨率 2048×1875，覆盖辽宁行政区范围；颜色、遮罩、高程采样和点位使用一致的 Mercator UV。市级下钻继续使用同一地理纹理，避免把整省纹理重新铺到城市上。模型通过约 6 万顶点的网格表达高程起伏，边界按行政区遮罩裁切；顶面点击通过地形交点判定城市，透明区域和内环不视为地表。
- 三维模式最多渲染 300 个有效点位，优先保留当前选中点；完整记录仍在菜单中。为控制负载，像素比上限 1.6，动画最多约 30 帧/秒，页面隐藏时不渲染，低动态偏好下停止脉冲动画。切换和卸载时释放几何、材质、纹理及事件监听。
- 本次未修改真实业务数据库，也未启动或替换后端服务。界面联调使用 `tests/fixtures/screenMapPreview.mjs` 的明确标注模拟数据，仅在测试浏览器中拦截 API 请求；生产路径不会导入该文件。

## 离线地形资源生成

`src/assets/terrain/metadata.json` 记录地理范围、投影范围、分辨率、高程编码上限和来源；`SOURCE_ATTRIBUTION.md` 保存上游完整署名要求。网页只加载打包后的本地纹理，不在用户浏览时请求外部地图瓦片。

需要重新生成纹理时，使用安装了 NumPy、Pillow、requests 的 Python 环境运行 `scripts/build_relief_assets.py`。脚本下载公开 Terrarium 高程瓦片，先解码高程再拼接、裁切和重采样，输出高程 PNG、灰色/绿色晕渲 WebP 和元数据。瓦片缓存位于忽略的 `temp/terrain-tiles`。纹理生成不依赖付费地图密钥。

## 根据推文重新区分两个场景（2026-10-20）

本轮重新对照用户提供的推文长截图。案例 1 的重点是厚地图、低视角、电力 HUD 与节点光柱；案例 2 的重点是地形、地面网格、较高视角与克制的周边图表。分别按下面的结构实现：

| 项目 | 立体态势 | 地理监测 |
|---|---|---|
| 投影 | 38° 视场角的透视相机，低角度观察 | 正交相机，可切换正射俯视/倾斜地形，并支持平移 |
| 地图结构 | 1.5 单位厚主板 + 有间距的下层支撑板 | 0.045 单位薄地表，突出实际高程分布 |
| 地形起伏 | 减小高度夸张，保留岩灰晕渲纹理 | 独立的地表高程网格和着色图例 |
| 装饰 | 蓝色渐变侧壁、底座光环、轮廓移动光点 | 无蓝色底座、光柱和轮廓流光，采用延展地面网格 |
| 点位 | 白色菱形、风险光晕和柔光柱 | 小型风险色点，选中时使用静态定位圈 |
| 页面布局 | 6 个指标、切角 HUD 卡片、常驻运行面板 | 3 个摘要指标、全高度地形、重新排列的两侧图表、可展开运行记录 |

轮廓流光仅沿已有行政区边界扫描，不生成虚构的输电连接或业务关系。小岛保留地理表面，但不挤出高厚度支柱，以免产生过大的装饰体积。坐标投影、高程资源和业务点位数据在两个场景之间一致。

图表容器加入 ResizeObserver 和卸载释放逻辑，场景切换后按新容器尺寸重排；已选城市和点位不会因仅切换场景而丢失。地理模式的“运行记录与服务状态”按钮展开任务、服务和日志；上方站点摘要以及地图点位按钮仍可打开点位菜单。

## 代码入口

- `src/components/map/TerrainMap.vue`：三维场景生命周期、交互及资源释放。
- `src/components/map/reliefScene.ts`：地形网格、遮罩、晕渲材质及光效。
- `src/utils/terrainAssets.ts`：离线纹理加载与采样缓存。
- `src/utils/mapGeometry.mjs`：坐标投影、GeoJSON 与点位配色。
- `src/pages/center/MapCenter.vue`：视图切换、点位菜单及现有接口接入。
- `src/pages/screen/Screen.vue`：地形模式的整体背景和面板风格。
- `src/store/screenData.ts`：地图风格偏好及现有城市筛选。
